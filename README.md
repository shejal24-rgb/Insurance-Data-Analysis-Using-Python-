# 🛡️ Insurance Data Analysis Using Python 📊


## 📌 Project Overview

This project analyzes insurance customer data using Python and popular data analysis libraries. It explores customer demographics, BMI, smoking habits, and insurance charges through exploratory data analysis (EDA) and data visualization.

## 🎯 Project Objectives

- Analyze customer age, gender, BMI, and number of children.
- Calculate average, minimum, and maximum insurance charges.
- Compare insurance charges between smokers and non-smokers.
- Analyze insurance charges across different regions.
- Explore relationships between age, BMI, and insurance charges.
- Create meaningful visualizations to identify patterns in the dataset.

## 🛠️ Technologies Used

- **Python** — Data analysis programming
- **Pandas** — Data manipulation and analysis
- **NumPy** — Numerical calculations
- **Matplotlib** — Data visualization
- **Seaborn** — Statistical visualization

## 📊 Dataset Information

The dataset contains 30 fictional insurance customer records.

| Column | Description |
|---|---|
| `Customer_ID` | Unique customer identifier |
| `Age` | Customer age |
| `Gender` | Customer gender |
| `BMI` | Body Mass Index |
| `Children` | Number of children |
| `Smoker` | Smoking status |
| `Region` | Customer region |
| `Insurance_Charges` | Sample insurance charges |

**Note:** This dataset is fictional and created for educational and portfolio purposes. It does not represent real insurance customers or actual insurance pricing.

## 📈 Data Visualizations

This project generates five visualizations:

1. Insurance Charges by Smoking Status
2. Age vs Insurance Charges
3. BMI vs Insurance Charges
4. Insurance Charges by Region
5. Distribution of Insurance Charges

## ⚙️ Installation

Install the required Python libraries:

```bash
python -m pip install pandas numpy matplotlib seaborn
```

## ▶️ How to Run the Project

**Step 1:** Clone or download this repository.

**Step 2:** Ensure the CSV file is saved inside the `data` folder.

**Step 3:** Open the terminal in the project directory.

**Step 4:** Execute the Python script:

```bash
python insurance_analysis.py
```

The program displays summary statistics and opens the data visualizations.
